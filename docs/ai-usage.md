## **Development Approach with AI**

After understanding the assessment requirements, I first planned the database structure, entity relationships, indexes, application architecture, and feature scope.

I used AI to review my proposed approach and suggest possible improvements. I evaluated those suggestions and selected the approaches that best matched the requirements and the scope of the application.

Once the technical decisions were finalized, I documented them in the requirements, design notes, and architecture files before starting implementation.

During development, I used an AI coding agent to accelerate implementation feature by feature. The existing planning and design documentation was provided as context so that generated code followed the intended architecture and requirements.

AI was also used to assist with generating unit tests.
